HOW TO USE

完成形から、あなたのサイトへ。

デザインを探し、動きを確かめ、プロンプトとコードを取得する。
今はすべての作品を、ログインなしで体験できます。

GENSEKIの使い方

  1. 01　作りたいサイトを探す

    キーワード、業種、目的、テイストで絞り込めます。気になる作品を選ぶと、デザインのポイントと実装している操作を確認できます。

  2. 02　ライブプレビューを体験する

    PC・スマートフォン幅を切り替え、メニューや画面の動きを実際に操作してください。作品は架空ブランドの概念デモで、実際の予約・注文・問い合わせは発生しません。

  3. 03　制作リソースを取得する

    作品詳細の「制作リソースを見る」から、プロンプト全文のコピーとサイトファイルのダウンロードができます。ZIPには公開版に対応するコード・プロンプト・起動説明が含まれます。

  4. 04　文章・画像を自分の内容にする

    編集項目は site/content.js にまとまっています。キャッチコピー、本文、画像URLなどを変更し、node prepare.mjs で反映します。AIで制作する場合はプロンプト内の編集項目を変更してください。

再現性を高めるため、プロンプトにはレイアウト・寸法・配色を固定する実装コードを含めています。AIやブラウザ、フォント、外部画像の状態による差異まで保証するものではありません。
