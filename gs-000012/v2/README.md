# 綴目 — グラフィックと編集のデザイン / v2

GENSEKI concept / `gs-000012`。架空スタジオの自主制作ポートフォリオです。実在する顧客・受賞・受託実績は主張しません。

主役は『あいだの設計 — 伝える順序のつくり方』。入口、読む距離、相談の余白を扱う3章のオリジナル原稿と、本文の関係を整理する模式図を収録しました。表紙の目次、ヒーローの見開き、作品詳細、全文を読む画面は同じ原稿を使っています。

## 起動とファイル

ビルド・npm・外部API・フォント取得は不要。このフォルダーをHTTP配信して `index.html` を開いてください。例: `python3 -m http.server 8173 --bind 127.0.0.1`。GitHub Pagesにも同じファイルを置けます。全参照は相対パスです。追加費用0円。

- `index.html`: 作品の探索と相談ノート
- `publication.html`: 同じ一冊の全文。JSを使わず読める静的HTML
- `publication.js`: 原稿dataと、ヒーロー/詳細用の紙面描画
- `app.js`: 冊子モーション、探索、詳細、相談ノート
- `telemetry.js`: 20秒の有界性能観測
- `style.css`: サイト/紙面/全文の版面とレスポンシブ構成
- `assets/*.svg`: すべて本作のオリジナル図版。OSフォント本体は配布しません
- `asset-manifest.json`: 素材のhashと出所

## 操作

冊子の表紙/見開き、click/touch/左右key、自動再生の停止/再開。reduce、非表示タブ、画面外では継続RAFを止めます。携帯は両面の縮小を避け、同じ第2章を一面へ再組版し、全文を読む経路を残しています。

4作品を媒体と検索語で探索し、詳細からノートへ追加/取消。目的、媒体、時期、相談内容を編集し、確認紙面へ反映します。ローカル保存/再訪復元、TXT/JSON書出し、JSON読込、印刷があります。実送信はありません。TXTと印刷は作品1件以上と目的が必要。途中の状態はJSONに保存できます。

書出す固定名は `tsuzume-project-note-v2.txt` と `tsuzume-project-note-v2.json`。JSON schemaはversion1を維持し、旧ノートを読み込めます。保存は同一origin/同一ブラウザのみで、別端末へはJSONを持ち帰ります。作品の追加/取消も未保存へ変わります。読込開始後に編集、リセット、別のfile選択をした場合は、古い非同期結果で現在のノートを上書きしません。

historyBackのpageshowでは、正本draftから入力と確認表示を再同期します。新しい自動保存は行いません。保存していない内容の保持はブラウザのページ復元に依存し、端末を閉じた後の継続は明示保存かJSONをお使いください。

## 観測

hidden output `#motion-diagnostics` のtextContentにJSONがあります。通常のsnapshotは最大1Hz。状態変更とPerformanceObserverの受信時は即時更新します。raw intervalは時刻付きで、直近20秒のactive時間に限定したring buffer（最大8192）です。300ms等の遅いframeを除外しません。停止/hidden/復帰最初の境界だけを除外します。非常に長い1frameが20秒窓を超える場合も生値を残し、overrunを表示します。容量超過はtruncatedとして明示します。

LCPは最新観測、CLSは最大session窓、longTasksは直近窓/最大128件。未対応はnullとsupport flagを返します。静止中のRAF cadenceを描画fpsとして計上しません。これらは観測用であり、実機や他環境の保証ではありません。
